<p>	The IQSS Dataverse Repository provides researchers with a robust data management and file handling system for sharing, managing, and preserving research datasets.&nbsp;</p>

<p>	The Harvard Dataverse Repository, supported by the Dataverse software, allows the storage and sharing of research datasets, enabling efficient data management, access, reuse, and preservation. Users can upload their data, describe it using metadata, and assign appropriate access levels to control who can view and download the data. There is support for a wide range of file formats and it allows for easy integration with numerous data preview and analysis tools.<br>&nbsp;</p>

<h3>	<strong>Come and learn about how Dataverse supports:</strong></h3>

<ul>	<li>
<h3>			Data Uploads (including file handling and additional ingest functionality for tabular data files)		</h3>
</li>	<li>
<h3>			Metadata Description, Access Control, and Versioning		</h3>
</li>	<li>
<h3>			Integrated data analysis and visualization tools, including file previewers and online survey data analysis using Data Explorer		</h3>
</li></ul>
