<p>This three hour workshop will focus on how to make maps using the two primary desktop GIS software programs QGIS and ArcGIS Pro. Using geographic data students will 1) Create both general reference maps and thematic maps that communicate particular geographic phenomena, 2) Become familiar with the fundamental principles of cartography, and 3) Learn some map design basics.</p>
