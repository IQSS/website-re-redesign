<p>This two-hour workshop introduces no-code visual programming for geographic analysis using KNIME. This workshop will: 1) Introdcue how to read, process, visualize, write GIS data and share workflow, 2) Build and evaluate machine learning and spatial modeling workflows, and 3) Demonstrate GenAI applications. Students will use the KNIME Analytics Platform and provided example workflows to perform various GIS tasks.</p>

<p>This workshop is free for Harvard affiliates with a valid Harvard ID, and is $100 for others.</p>
