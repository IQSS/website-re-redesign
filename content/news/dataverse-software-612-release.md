Dataverse 6.12 is now available with several new features, bug fixes, and improvements.

## Highlights for Dataverse 6.12 include:

- HTML is now supported in the description of files.
- "Translator" is now available as a "Type" under the "Contributor" field.
- External vocabulary scripts now support the use of multiple PID services per field. For example, the Author field can allow both an ORCID value and a ROR value.
- New and improved APIs
- Bug fixes
- Security fixes
- Performance improvements

Thank you to all community members who contributed code, suggestions, bug reports, and other assistance across the project.

View release details and upgrade instructions here: <https://github.com/IQSS/dataverse/releases/tag/v6.12>
